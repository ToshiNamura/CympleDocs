# Запись датасета

На каждой странице отслеживания есть панель **Record Dataset**, по умолчанию свёрнутая. Она
сохраняет сырые кадры, которые получает консоль, вместе с выводом решателя — так можно разобрать
сессию офлайн, сравнить сборки или подготовить данные для собственного обучения.

## Где она находится

| Страница | Подзаголовок панели | Содержимое |
|---|---|---|
| [Eye](../software/eye.md) | *"Expand to enter eye-tracking dataset recording."* | Кадры левого и правого глаза |
| [Dual-Camera Mouth](../software/dual-camera-mouth.md) | *"Expand to enter stereo mouth-tracking dataset recording."* | Стереопара |
| [Single-Camera Mouth](../software/single-camera-mouth.md) | *"Expand to enter mouth-tracking dataset recording."* | Один кадр |

## Зачем записывать

| Цель | Чем помогает датасет |
|---|---|
| Разобраться, «почему рот выглядит неправильно» | Видно, что именно видела камера и что из этого сделал решатель |
| Сравнить версии прошивки | То же лицо, то же освещение, две сборки |
| Сравнить настройки фильтров | Объективное «до и после» вместо воспоминаний |
| Помочь проекту | Размеченные данные — самый дефицитный ресурс самодельного трекера |
| Обучить личную модель | Ваше лицо, ваш шлем, ваше освещение |

## Планирование сессии

1. **Меняйте одну переменную.** Одно освещение, одна посадка шлема, один набор значений фильтров.
2. **Запишите сценарий.** Проговорите фиксированный список выражений: нейтральное лицо, улыбка,
   нахмуренные брови, широко открытая челюсть, вытянутые губы, медленное моргание, быстрое
   моргание, взгляд влево, взгляд вправо, высунутый язык.
3. **Оставьте нейтральные кадры.** Несколько секунд спокойного лица — опора для любого последующего
   разбора.
4. **Повторите дважды.** Два дубля на одно условие показывают, реально ли различие.
5. **Запишите метаданные** в текстовый файл рядом с записью: версия, профиль, ПК, GPU, освещение,
   значения фильтров.

## Объём и хранение

Сырые кадры камеры занимают много места. Ориентировочно:

| Материал | На минуту (порядок величины) |
|---|---|
| Пара глаз, 640×480 | десятки МБ |
| Стереорот, 640×480 × 2 | от десятков до ~100 МБ |
| Вместе с выводом решателя | примерно вдвое больше |

Записи складываются в локальный каталог данных консоли. Проверьте свободное место перед длинной
сессией и переносите готовые наборы на другой диск.

## Приватность

Запись содержит изображения вашего лица и глаз. Относитесь к ней как к персональным данным:

- не публикуйте сырой набор без согласия всех, кто в нём есть;
- размывайте или обрезайте кадры, прежде чем прикладывать скриншоты к отчёту об ошибке;
- сообщая о проблеме, лучше берите короткие фрагменты, а не длинные сессии;
- помните, что вместе с отчётом об ошибке уходит и INI-файл конфигурации — см.
  [Feedback](../software/feedback.md).

## Как выглядит хорошая запись

| Свойство | Хорошо | Плохо |
|---|---|---|
| Освещение | Ровное, рассеянное | Контровой свет, одиночный яркий блик |
| Кадрирование | Лицо занимает кадр, виден нос | Рот на самом краю |
| Движение | Осознанное, одно выражение за раз | Постоянная возня |
| Длительность | 30–60 с на дубль | 20 минут бесцельного движения |
| Разметка | Записанный сценарий, отмечены метки времени | «Я просто подвигался лицом» |

## После записи

1. Просмотрите кадры — смысл упражнения именно в том, чтобы *увидеть* сбой.
2. Отметьте в секундах диапазон кадров, на котором отслеживание сломалось.
3. Повторите запись, изменив одну настройку.
4. Оставьте только пары, которые документируют реальное различие; остальное удалите.
