# Настройка VRChat

Отслеживание в консоли — только половина дела: аватар должен принимать параметры. Эта страница
описывает сторону VRChat для обоих путей передачи данных.

## 1. Включите OSC в VRChat

**Action Menu → Options → OSC → Enabled** (или аналог в вашей сборке VRChat).

Этот единственный переключатель позволяет VRChat отправлять поток параметров (чтобы консоль видела
аватар) и принимать данные отслеживания.

## 2. Проверьте порты

| Направление | Порт по умолчанию | Владелец |
|---|---|---|
| VRChat → приложения (его *выход*) | `9001` | Здесь слушает Cymple |
| Приложения → VRChat (его *вход*) | `9000` | Сюда отправляет Cymple |

Если данные не приходят, добавьте параметр запуска из [OSC Router](../software/osc-router.md):

```text
--osc=9000:127.0.0.1:9001
```

Steam → **VRChat → Properties → General → Launch Options**, затем перезапустите VRChat.

## 3. Параметры аватара

Cymple управляет стандартным набором параметров, совместимым с VRCFaceTracking: 28 выражений плюс
значения глаз и взгляда. Аватар должен предоставлять параметры с теми же именами.

### Через VRCFaceTracking (рекомендуется, если аватар уже настроен под отслеживание мимики)

1. Добавьте [VRCFaceTracking](https://vrcft.io) в проект Unity (Avatar Setup / Unified
   Expressions из VRCFT).
2. Запустите его настройку на своём аватаре и дайте создать список параметров и анимации.
3. Загрузите аватар.
4. В игре убедитесь, что параметры `Face Tracking` / OSC не блокируются собственным меню аватара.

### Через VRC Direct

VRC Direct пишет OSC-параметры напрямую. Аватару всё равно нужны параметры и слои анимации,
которые их читают: Cymple поставляет данные, а не риг. Если аватар собран под VRCFT, всё это у него
уже есть.

## 4. Типичные имена параметров

Имена следуют соглашениям VRCFT/VRChat:

| Область | Примеры |
|---|---|
| Глаза | `EyeLeft`, `EyeRight`, `EyeLidLeft`, `EyeLidRight`, `PupilDilation` |
| Выражения | `JawOpen`, `MouthClosed`, `Smile`, `BrowDownLeft`, `CheekPuff`, … |

Регистр имеет значение. Список на странице [Expression Amplitude](../software/expression-amplitude.md)
— это имена в самой консоли; сопоставьте их с именами параметров аватара в аниматоре или возьмите
готовую настройку аватара под VRCFT, где это уже сделано.

## 5. Проверка в игре

1. Запустите консоль, затем SteamVR, затем VRChat.
2. Откройте приватный мир с зеркалом.
3. Моргните — веки должны отреагировать.
4. Посмотрите влево и вправо — зрачки должны двигаться.
5. Улыбнитесь, откройте челюсть, надуйте щёки.
6. Если ничего не двигается, смотрите **Output Rate** на странице [VRCFT](../software/vrcft.md).

## 6. Амплитуды для каждого аватара

Как только VRChat сообщает аватар, красный баннер **Current avatar not detected** на странице
[Expression Amplitude](../software/expression-amplitude.md) исчезает, а правки применяются к профилю
этого аватара. Загрузите каждый аватар, которым пользуетесь, настройте его один раз — консоль
запомнит.

## Диагностика

| Симптом | Что проверить |
|---|---|
| Консоль так и не видит аватар | OSC выключен в игре, неверные порты, брандмауэр |
| Часть выражений не двигается никогда | Параметра нет на аватаре или амплитуда стоит `0` |
| Выражения двигаются не в ту сторону | Отображение в аниматоре, а не трекер — проверьте по зеркалу и по выводу консоли |
| Глаза двигаются, рот нет | Трекер мимики офлайн или `Face Tracking` выключен на [Home](../software/home.md) |
| Всё работает несколько минут, потом останавливается | Провал Wi-Fi — см. [Настройка сети](../hardware/network.md) |

## Настройки безопасности, о которых стоит знать

- Панель **OSC Debug** в VRChat — самый быстрый способ увидеть, приходят ли параметры вообще.
- У некоторых аватаров в меню есть переключатель «face tracking off»; убедитесь, что он включён.
- Системы модерации и жалоб при этом не затрагиваются — Cymple только передаёт параметры.
