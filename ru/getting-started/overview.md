# Обзор

## Что такое Cymple

Cymple — это **система отслеживания взгляда и мимики для VR, рассчитанная на самостоятельную
сборку**. Железо намеренно простое: один-два камерных модуля ESP32 на трекер, напечатанное
крепление, которое цепляется за шлем, и питание по USB. Всё дорогое — компьютерное зрение,
фильтрация, решение выражений, маршрутизация OSC — выполняется на ПК внутри **Cymple Console**.

В этом разделении и состоит вся идея:

- устройству достаточно захватить изображение и отправить его по Wi-Fi;
- ПК может потратить на обработку настоящие вычислительные ресурсы (инференс на CUDA, временные
  фильтры, калибровка под конкретного пользователя);
- протокол — обычный OSC, поэтому результат может принять любое приложение, которое его понимает.

## Семейство продуктов

| Продукт | Что отслеживает | Камеры | Где находится |
|---|---|---|---|
| **Cymple Eye** | Направление взгляда, расширение зрачка, степень открытия век | 2 (по одной на глаз) | Внутри шлема, рядом с линзами |
| **CympleFace Dual-Camera Mouth** | Челюсть, губы, щёки, язык | 2 (стереопара) | Под шлемом, направлен на нижнюю часть лица |
| **CympleFace Single-Camera Mouth** | Тот же набор выражений, точность ниже | 1 | Под шлемом, направлен на рот |
| **Cymple Console** | — | — | Приложение для Windows, мозг системы |
| **Cymple VRCFT Module** | — | — | Плагин, который позволяет VRCFaceTracking получать данные Cymple |

Полный комплект (`Eye` + трекер рта) управляет обоими глазами и 28 выражениями лица, перечисленными
в [Амплитуде выражений](../software/expression-amplitude.md). Любую половину можно использовать
отдельно.

## Поток данных

```text
┌──────────────┐   Wi-Fi (JPEG frames)   ┌────────────────────┐
│ ESP32 camera │ ──────────────────────► │                    │
│  left eye    │                         │   Cymple Console   │
└──────────────┘                         │  ┌──────────────┐  │
┌──────────────┐                         │  │ vision +     │  │
│ ESP32 camera │ ──────────────────────► │  │ solver       │  │
│  right eye   │                         │  └──────┬───────┘  │
└──────────────┘                         │         │          │
┌──────────────┐                         │  ┌──────▼───────┐  │
│ mouth camera │ ──────────────────────► │  │ OSC / VRCFT  │  │
└──────────────┘                         │  └──────┬───────┘  │
                                         └─────────┼──────────┘
                                                   │ OSC 9000 / 22999 UDP
                                          ┌────────▼─────────┐
                                          │ VRChat / VRCFT   │
                                          │ avatar           │
                                          └──────────────────┘
```

Путей доставки два, и по замыслу они взаимоисключающие:

1. **VRC Direct** — консоль сама общается с VRChat по OSC. Больше ничего не требуется.
2. **Внешний VRCFT** — VRCFaceTracking загружает модуль Cymple и передаёт данные аватару через
   собственный слой OSC. Удобно, когда вы совмещаете Cymple с другими трекерами или вам нужен
   единый набор параметров VRCFT.

Для второго пути **VRC Direct** должен быть выключен: пакеты совместимости консоль отправляет
только при отключённом прямом режиме. Подробности — в разделе [VRCFT](../software/vrcft.md).

## В чём Cymple силён

- **Цена.** Самодельный айтрекер стоит малую долю от коммерческого устройства.
- **Ремонтопригодность.** Модули — серийные платы ESP32; сломавшуюся камеру меняют за копейки.
- **Возможность доработки.** Прошивка открыта, протокол описан, консоль показывает свои фильтры.
- **Задержка.** Локальный Wi-Fi, без обмена через облако; консоль ставит метки времени и сглаживает
  данные на месте.

## Чем Cymple не является

- **Не медицинское и не биометрическое устройство.** Точность взгляда потребительская — в лучшем
  случае единицы градусов, и она сильно зависит от посадки.
- **Не plug-and-play.** Рассчитывайте на вечер печати, прошивки и калибровки.
- **Не универсален по шлемам.** Крепление должно физически подходить к вашему шлему; в репозитории
  есть крепления для Quest 2/3/3S/Pro, Pico 4/Neo 3, Pimax Crystal/Dream Air, PSVR2 и универсальный
  зажим.
- **Не работает без питания.** Камерам нужно электричество; понадобится USB-батарея или порт самого
  шлема.
