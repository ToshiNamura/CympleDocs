# Требования

## ПК

| Параметр | Минимум | Рекомендуется | Зачем |
|---|---|---|---|
| ОС | Windows 10 64-бит (1909+) | Windows 11 64-бит | Консоль, драйвер OpenVR и прошивальщик работают только в Windows |
| Процессор | 4 ядра / 8 потоков | 6 ядер или больше | По одному потоку декодирования и инференса на каждую камеру |
| ОЗУ | 8 ГБ | 16 ГБ | Основной потребитель памяти — сам VRChat |
| Видеокарта | GPU класса DirectX 11 | NVIDIA GTX 1650 SUPER или лучше (CUDA) | Инференс мимики на CUDA идёт заметно быстрее; устройство вывода выбирается в [Face Settings](../software/face-settings.md) |
| Свободное место на диске | 2 ГБ | 10 ГБ | Консоль, журналы, записи датасетов |
| USB | 1 свободный порт | 2 | Прошивка и питание трекера во время проверки |

Консоль спокойно работает и на встроенной графике, но ожидайте меньший FPS и более высокую
нагрузку на процессор: решатель мимики переключается на CPU. На эталонной машине, с которой сняты
наши скриншоты, стоит **NVIDIA GeForce GTX 1650 SUPER** — это реалистичная нижняя планка.

## Шлем

- Для работы *драйвера* подойдёт любой шлем SteamVR. От шлема зависит только крепление.
- Готовые крепления: Quest 2, Quest 3, Quest 3S, Quest Pro, Pico 4/4 Pro/4U, Pico Neo 3, Pimax
  Crystal, Pimax Dream Air/SE, PSVR2, плюс универсальный клеевой зажим.
- Автономное отслеживание на Quest **не** заработает через один Link/Air Link — консоли нужно,
  чтобы шлем запускал SteamVR на ПК.

## Сеть

| Требование | Подробности |
|---|---|
| Пропускная способность | 2,4 ГГц хватает одной камере для глаза; для стереотрекера рта настоятельно рекомендуется 5 ГГц |
| Подсеть | ПК и все трекеры должны быть в **одной сети L2** |
| Адресация | Постоянный IP на каждое устройство (резервирование DHCP или статический IP в самом устройстве) |
| Изоляция | Гостевая сеть Wi-Fi, AP isolation и «изоляция клиентов» должны быть **выключены** |
| Межсетевой экран | Разрешите консоли доступ через Windows Defender Firewall в частных сетях |

Каждая камера — небольшой HTTP/MJPEG-сервер. Консоль забирает кадры с IP, который вы вводите в
[Eye](../software/eye.md) → **Left/Right Eye Device Information** или в **Device Info** на страницах
рта.

> **Совет.** Если на роутере есть отдельный SSID для «игр» или «IoT», убедитесь, что он не изолирован
> от основного. AP isolation — самая частая причина сообщения *Waiting for image*.

## Программное обеспечение

| Компонент | Для чего нужен | Где взять |
|---|---|---|
| Cymple Console | Для всего | Поставляется подписанным установщиком или портативным ZIP |
| Драйвер OpenVR (`driver_cymple.dll`) | Чтобы SteamVR видел трекер как аксессуар шлема | Лежит в `openvr驱动/cymple/` в репозитории |
| VRCFaceTracking | Только при выборе пути с внешним VRCFT | [vrcft.io](https://vrcft.io) |
| Модуль Cymple для VRCFT | Только для внешнего пути | [CympleFaceTracking releases](https://github.com/Dominocs/CympleFaceTracking) |
| VRChat с включённым OSC | Вывод на аватар | В игре: **Options → OSC → Enabled** |
| Драйвер USB-COM (CH340 / CP210x) | [Прошивка](../software/firmware-flash.md) | Драйвер производителя, обычно ставится автоматически |

## Права

- **Права администратора** нужны только для двух операций: установки драйвера OpenVR в
  `SteamVR/drivers` и прошивки через COM-порт.
- Если калибровка диапазона взгляда не запускается, действует подсказка самой консоли:
  *«If you encounter any issues, run this application as administrator.»*

## Что вам **не** понадобится

- Отдельный донгл для самодельной сборки — устройство работает только по Wi-Fi.
- Аккаунт Meta, вход в облако или лицензия на рабочее место для консоли.
- Базовые станции. Cymple не расширяет зону трекинга: он добавляет данные взгляда и мимики поверх
  собственных 6DoF шлема.
