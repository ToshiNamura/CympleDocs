# Глоссарий

## A–F

**Amplitude** — амплитуда, коэффициент усиления одного выражения. `1.00` — нейтральное значение; `0`
подавляет блендшейп, `2` удваивает его. См.
[Expression Amplitude](../software/expression-amplitude.md).

**AP isolation / client isolation** — изоляция клиентов: функция роутера, которая запрещает клиентам
общаться друг с другом. Она ломает любую схему с Cymple. Должна быть выключена.

**Blendshape** — блендшейп, именованная деформация 3D-модели. VRChat отдаёт их как параметры
аниматора; Cymple управляет ими по OSC.

**CUDA** — вычислительная платформа NVIDIA. С ней вывод лица работает заметно быстрее, отсюда советы
по GPU в [Требованиях](../getting-started/requirements.md).

**Direct mode / VRC Direct** — прямой режим: встроенный в консоль путь к VRChat. Включён — консоль
сама говорит с VRChat. Выключен — консоль только отправляет поток совместимости для внешнего модуля
VRCFaceTracking.

**FPS / PPS** — FPS: кадры в секунду, полученные от камеры; PPS: обработанные отсчёты в секунду,
то есть кадры, которые решатель принял. Большой разрыв между ними указывает на изображение, а не на
сеть.

## G–M

**Gaze** — взгляд, направление взгляда в виде нормализованного 2D-смещения. Cymple сглаживает его
фильтром **Eye Gaze Filter** и масштабирует **Eye Gaze Amplitude**.

**INI file** — INI-файл, текстовое хранилище настроек в `%LOCALAPPDATA%\Cymple\iniFile.ini`. См.
[Файл конфигурации](config.md).

**MJPEG** — Motion JPEG: поток независимых JPEG-кадров по HTTP. Именно его отдаёт каждая камера и
забирает консоль.

**Module (VRCFT)** — модуль VRCFT: DLL, которая добавляет VRCFaceTracking новый источник данных.
Cymple поставляет такой модуль (`CympleFaceTracking`).

## N–S

**OpenVR driver** — драйвер OpenVR, `driver_cymple.dll`; его загружает SteamVR, чтобы среда знала о
трекере и могла запускать и останавливать консоль вместе с собой.

**OSC** — Open Sound Control: небольшой протокол сообщений поверх UDP. На нём говорит VRChat и всё,
с чем работает Cymple.

**Precise Calibration** — точная калибровка: более медленный и более точный расчёт на странице
[Eye](../software/eye.md).

**Priority (module)** — приоритет модуля: домен данных забирает модуль с меньшим числом. У Cymple он
фиксирован — `0` («Fixed Highest»).

**Pupil dilation** — расширение зрачка: изменение размера зрачка, передаётся в диапазоне `0–1` и
масштабируется **Pupil Dilation Amplitude**, где `1` сохраняет исходное значение, а `0` держит
нейтральное.

**Recenter** — перецентровка: сброс нейтрального центра глаз и базовых линий век. Секунда, каждую
сессию.

**ROI** — region of interest, область интереса: прямоугольник, который решатель мимики считает ртом.
Может задаваться автоматически или рисоваться вручную.

**Saccade** — саккада, быстрый скачок взгляда. Поэтому диапазонная калибровка и важна: без неё
саккады обрезаются.

## T–Z

**Tracker kit** — готовый комплект, аппаратная альтернатива самоделке: уже прошит и смонтирован.

**VRCFaceTracking (VRCFT)** — открытый интегратор отслеживания мимики и его стандарт параметров.
Cymple и эмулирует его, и поставляет для него модуль.

**VRChat avatar parameter** — параметр аватара VRChat: именованное значение, которое читает аниматор
аватара. Если имя не совпадает, данные молча отбрасываются.

## Числа, которые вы встретите

| Число | Значение |
|---|---|
| `9000` | OSC-порт приёма в VRChat; сюда отправляет Cymple |
| `9001` | OSC-порт отправки из VRChat; здесь слушает Cymple |
| `9002` | Порт входа устройств Cymple для пересылки стороннего OSC |
| `22999` | UDP-порт пакета совместимости Cymple→VRCFT (70 полей) |
| `4.20.2` | Версия консоли, описанная в этой вики |
