# Файл конфигурации

## Расположение

| Путь | Роль |
|---|---|
| `%LOCALAPPDATA%\Cymple\iniFile.ini` | Основное хранилище настроек |
| `C:\Cymple\iniFile.ini` | Устаревший запасной путь; модуль VRCFT читает его, если основного файла нет |

Перед правкой сделайте резервную копию. В файле хранятся IP устройств, все амплитуды по аватарам и
настройки пути передачи — потеря означает повторную настройку.

## Что там лежит

| Группа | Примеры |
|---|---|
| Общие | Язык, тема, жизненный цикл SteamVR, действие при закрытии окна |
| Глаза | IP камер, значения фильтров, амплитуды, состояние калибровки |
| Мимика | IP, диапазон/смещение/поворот камеры, сила фильтра, режим ROI |
| Выражения | Наборы амплитуд по аватарам плюс набор по умолчанию |
| Вывод | Прямой режим, порты OSC, цели роутера |
| Диагностика | Подробность журнала |

## Ключи, которые можно встретить

Точные имена ключей меняются от релиза к релизу; смотрите их в собственном файле, а не копируйте
фрагмент из старого руководства.

| Секция | Ключ | Значение |
|---|---|---|
| `Cymple_Mouth` | `reset_expression_on_tracking_disconnect` | `1` — сбрасывать выражения после обрыва, `0` — удерживать последний кадр. Модуль VRCFT читает ключ раз в секунду |
| `Cymple_Eye` | `cymple_eye_sw` | Состояние аппаратного переключателя глаз. Не может отключить вход *другого* приложения через модуль |
| `Cymple_Mouth` | `cymple_mouth_sw` | Состояние аппаратного переключателя мимики, оговорка та же |

> Внутри VRCFaceTracking модуль намеренно игнорирует оба аппаратных переключателя. Локальные
> переключатели на одной машине не должны молча отключать отслеживание в другом приложении — это
> осознанное решение, а не ошибка.

## Безопасная правка

1. **Закройте консоль.** Она записывает файл при изменениях; правка на ходу теряется.
2. Скопируйте `iniFile.ini` в `iniFile.backup.ini`.
3. Правьте простым текстовым редактором (UTF-8, без BOM).
4. Соблюдайте грамматику INI: `key=value`, по одной паре в строке, заголовки `[Section]` в
   квадратных скобках.
5. Запустите консоль и проверьте [Logs](../software/logs.md) на ошибки разбора.
6. Если что-то сломалось, восстановите копию.

## Сброс к значениям по умолчанию

| Область | Как |
|---|---|
| Один ползунок | Значок ⟲ рядом со значением на его странице |
| Одна страница | Введите заново значения по умолчанию, описанные в этой вики |
| Всё сразу | Закройте консоль, переименуйте `iniFile.ini`, запустите снова — файл создастся заново |

Сброс всего файла заодно стирает калибровку, IP устройств и настройки аватаров. Пока вы разбираетесь
с проблемой, предпочитайте сброс по страницам.

## Наборы амплитуд для отдельных аватаров

Когда VRChat сообщает аватар, консоль привязывает набор амплитуд именно к нему. Практическое
следствие: правка амплитуд без загруженного аватара записывает **профиль по умолчанию**, который
наследуют все ненастроенные аватары. Поэтому на странице
[Expression Amplitude](../software/expression-amplitude.md) и висит красная плашка
*"Current avatar not detected"* — она показывает, какой профиль вы на самом деле правите.

## Передача файла

Файл конфигурации содержит ваши локальные IP-адреса и имена параметров аватара. Прежде чем
прикладывать его к публичному issue, считайте его персональными данными;
[Feedback](../software/feedback.md) прикладывает файл автоматически — это удобно, и об этом стоит
знать.
